FEM Lab Web Static

Versione web statica del tool FEM Lab.
Aprire index.html o pubblicare la cartella su GitHub Pages, Cloudflare Pages o come file statico separato.
Il solver viene eseguito nel browser, senza MATLAB, login o server di calcolo.

Contenuto:
- index.html con dati dei casi studio incorporati
- calcolo FEM live in JavaScript
- interfaccia Dark Cinematic
